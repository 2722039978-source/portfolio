# 开发说明

## 页面与设计系统

首页依次展示介绍、Latest Journal、Selected Works、Experimental Lab 和 About。文章入口使用明确的文字链接。暖白与深墨作为基础色，紫色用于主要链接与几何图形，橙色、蓝色与荧光绿用于局部强调。Space Grotesk、DM Sans 与系统中文字体组成字体层级。

全局导航、页脚、按钮、标签、内容容器和主题由共享组件及 Token 控制。页面进入动画使用 opacity 和 transform，移动端缩短动画，`prefers-reduced-motion` 关闭动画与平滑滚动。主题选择保存到本地。

文章列表支持正文搜索、分类、标签和查询参数。详情使用 ReactMarkdown 与 remark-gfm，支持标题目录、代码、表格、相邻文章和未知文章提示。代码与表格在各自容器内滚动。

## 文件职责

- `src/pages`：首页、列表、详情和 404 页面。
- `src/components`：布局、文章入口、排版实验、GitHub 数据展示。
- `src/styles`：设计 Token 和页面样式。
- `src/data`：文章、分类、精选项目与公开资料配置。
- `src/services/github.ts`：公开 API 请求、数据检查、缓存和网络状态。
- `tests`：真实浏览器交互、响应式与文章完整性检查。
- `public/favicon.svg`：站点图标。

## 验证方法

使用 Playwright 驱动实际 Google Chrome，检查 DOM、计算样式、控制台、页面尺寸和真实交互。默认桌面为 1440 × 1000，移动端为 390 × 844。完整响应式检查覆盖 320、375、390、640、641、768、960、1280、1440、1920 十个宽度及深浅主题。

文章保护检查使用固定 SHA256，不依赖旧项目目录。隐私检查验证默认配置不出现邮箱链接、账号链接或 GitHub 请求。已配置 GitHub 账号时，集成检查使用真实请求与浏览器原生离线状态。

GitHub API 成功展示依赖访问环境；错误、超时、离线状态具有可阅读提示与重新请求入口。未配置账号的检查结果不代表成功响应已经通过验证。

GitHub 当前目录只包含新版源代码、依赖锁文件、站点图标、测试和文档。旧项目目录、旧 Dashboard 组件、未使用的背景图片、本机测试记录、构建产物、依赖目录、真实环境配置及 Sites 关联配置均不纳入本次发布。
